📷 인바디 사진 읽기 (직접 숫자 선택 OCR v1.9.20)

인터넷 연결 필요 · 사진을 선택한 뒤 체중, 골격근량, 체지방률, 측정 날짜를 순서대로 눌러줘. 날짜는 사진을 6개 영역으로 나눠 자동 검색해. 실패하면 결과지에 인쇄된 날짜를 4번째로 직접 눌러줘. 숫자를 순서대로 터치하면 서로 일치하는 OCR 결과만 자동 입력해. 불일치하면 후보를 직접 확인해줘. 반드시 원본과 비교한 후 저장해. 자동 저장되지 않아.

선택한 사진 없음

사진을 선택하면 숫자를 직접 지정할 수 있어.

🔎 실제 OCR 이미지 미리보기

빨간 표시를 누른 위치 주변의 원본 확대와 OCR 처리 결과야. 숫자가 잘렸는지 확인해줘.

인식 후보 확인

불확실한 값은 자동 입력하지 않아. 원본 숫자와 같을 때만 후보 버튼을 눌러 입력해.

🔎 이번 사진 측정 분석 · 저장 전

인식된 수치를 확인하고 실제 측정 날짜를 선택해. 이 분석은 저장되지 않은 임시 미리보기야.

측정일과 수치를 확인하면 이번 사진의 분석이 표시돼.

📈 저장된 인바디 전체 종합 분석

최신 유효 측정일의 분석이 대표로 표시돼. 최초·직전 기록과 비교하고, 아래 날짜를 누르면 과거 분석을 펼쳐 볼 수 있어. 외부 AI 비용 없이 기기에서 계산해.

기록을 저장하면 분석이 표시돼.

🔔 휴식 알림

다른 앱을 볼 때 알림을 시도해. 웹앱 특성상 백그라운드에서 정시 알림은 보장되지 않아.

내 데이터

업데이트 전후로 JSON 백업을 내려받아 별도 보관해 줘. 기존 기록 저장 키는 그대로 유지돼. v1.2 첫 실행 시 운동 목록만 호연 전용으로 교체하고 이전 운동 목록은 내부 보관해.

운동·인바디 기록은 이 브라우저에만 저장돼. 앱 삭제, 사이트 데이터 삭제, 기기 고장 시 사라질 수 있으니 정기적으로 백업해.
