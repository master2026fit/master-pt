설치 안내

이 폴더를 HTTPS 정적 호스팅에 올린 다음 삼성 인터넷 또는 크롬에서 열고 메뉴의 홈 화면에 추가 / 앱 설치를 선택해. 파일을 직접 열면 PWA 설치와 오프라인 기능이 작동하지 않을 수 있어.

회원가입·서버·AI API 없이 동작하며, 휴대폰끼리 자동 동기화되지는 않아.
